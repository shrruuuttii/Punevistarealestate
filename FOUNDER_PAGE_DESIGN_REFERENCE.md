## ?? Responsive Breakpoints

### Desktop (1200px and above)
```
Hero Section:       Two-column layout
Floating Stats:     Absolutely positioned
Grid Columns:       3-4 columns
Font Sizes:         Full scale
Spacing:            Generous padding
Animation:          All enabled
```

### Tablet (768px - 1199px)
```
Hero Section:       Two-column (adjusted)
Floating Stats:     Normal cards
Grid Columns:       2 columns
Font Sizes:         Slightly reduced
Spacing:            Medium padding
Animation:          Hover effects only
```

### Mobile (< 768px)
```
Hero Section:       Single column stack
Floating Stats:     Normal cards (no animation)
Grid Columns:       1 column (full width)
Font Sizes:         Mobile optimized
Spacing:            Compact padding
Animation:          Minimal (performance)
Touch Targets:      44x44px minimum
```

## ?? Section-Specific Animations

### Hero Section
```
Entrance:
  - Intro Badge:     slideInDown 0.8s
  - Main Heading:    slideInUp 0.8s delay 0.2s
  - Subtitle:        fadeIn 0.8s delay 0.4s
  - Designation Box: slideInUp 0.8s delay 0.3s
  - CTA Buttons:     slideInUp 0.8s delay 0.4s
  - Founder Image:   slideInRight 0.8s delay 0.2s
  - Floating Stats:  float 3s infinite (staggered)
```

### Story Cards
```
On Hover:
  - Card:  translateY(-10px) shadow increase
  - Icon:  scale(1.15) rotate(5deg)
  - Border: Top border animates scaleX(0?1)
```

### Feature Cards
```
On Hover:
  - Card:  translateY(-8px) shadow increase
  - Icon:  scale(1.1) rotate(-5deg) shadow increase
```

### Service Cards
```
On Hover:
  - Card:  translateY(-12px) shadow increase
  - Image: scale(1.12)
  - Overlay: opacity(0?1)
```

## ?? Micro-Interactions

### Button Click
```
1. Visual feedback (slight scale down)
2. Smooth color transition
3. Shadow adjustment
4. Navigation or form submission
```

### Card Hover (Desktop Only)
```
1. Slight lift animation (translateY)
2. Shadow enhancement
3. Border color change
4. Icon rotation/scale
5. Smooth 300ms transition
```

### Form Input
```
1. Border color change on focus
2. Shadow appearance on focus
3. Cursor indicates text input
4. Validation feedback
```
